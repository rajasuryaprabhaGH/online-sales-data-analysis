# Online Sales Data Analysis

## Project Overview

This project analyzes online sales data using Python to understand revenue patterns, product performance, regional performance, payment methods, and sales trends.

The project covers data cleaning, data processing, exploratory data analysis (EDA), visualization, and business insights.

## Objectives

- Clean and preprocess the sales dataset
- Check for missing values and duplicate records
- Identify and analyze outliers
- Analyze revenue and units sold
- Identify top-performing products and categories
- Compare revenue across regions
- Analyze payment methods
- Analyze monthly revenue trends
- Generate data-driven business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Data Analysis and Visualization

The project includes:

- Total Revenue Distribution
- Revenue by Product Category
- Revenue by Region
- Revenue by Payment Method
- Top 10 Products by Revenue
- Monthly Revenue Trend
- Correlation Heatmap
- Units Sold by Product Category

## Data Cleaning

The dataset was examined for:

- Missing values
- Duplicate records
- Outliers
- Data types
- Product-name consistency

Using the IQR method, 19 high-value revenue records were identified as statistical outliers. These records were retained for analysis rather than automatically removed.

No duplicate rows were identified.

## Key Insights

The analysis provides insights into:

- Product category performance
- Regional revenue performance
- Payment method contribution
- Top-performing products
- Monthly revenue patterns
- Relationships between numerical variables

## Business Recommendations

- Focus on high-performing product categories.
- Maintain appropriate inventory for high-performing products.
- Strengthen strategies in high-performing regions.
- Monitor payment method performance.
- Review lower-performing categories and regions.
- Monitor high-value transactions during future analysis.

## Conclusion

This project demonstrates the use of Python for data cleaning, exploratory data analysis, visualization, and extracting useful insights from online sales data.

The analysis can support better understanding of sales performance and help identify areas for further business analysis.
